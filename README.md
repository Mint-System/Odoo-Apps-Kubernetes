# Odoo Apps: Kubernetes

Odoo modules extending the `kubernetes` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Kubernetes.git ./addons/kubernetes
```

## Available modules

| Module | Summary |
| --- | --- |
| [base_mintcloud](base_mintcloud) |         Mint Cloud product data. |
| [helm_import](helm_import) |         Import data from Helm repo. |
| [helm](helm) |         Apply Helm charts. |
| [helm_mintcloud](helm_mintcloud) |         Mint Cloud helm data. |
| [helm_portal](helm_portal) |         Update Helm releases in portal. |
| [kubectl_contacts](kubectl_contacts) |         Contacts filter for provider and consulting partners. |
| [kubectl_import](kubectl_import) |         Import data from existing Kubernetes cluster. |
| [kubectl](kubectl) |         Manage kubectl configuration. |
| [kubectl_mintcloud](kubectl_mintcloud) |         Mint Cloud cluster data. |
| [sale_helm](sale_helm) |         Sell services and assign hosting provider and consulting partner. |
| [website_kubectl](website_kubectl) |         Present Kuberentes clusters on website. |
| [website_kubectl_mintcloud](website_kubectl_mintcloud) |         Mint Cloud website data. |
| [website_sale_helm](website_sale_helm) |         Apply Helm Charts when a product is bought. |
| [website_sale_helm_mintcloud](website_sale_helm_mintcloud) |         Mint Cloud website data. |
